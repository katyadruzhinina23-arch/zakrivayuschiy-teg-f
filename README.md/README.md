# **Закрывающий тег**

Персональная страница-рефлексия о прохождении курса по веб-разработке.  
Проект выполнен в пиксельной эстетике и рассказывает о пути от нулевого спринта до текущего момента.

## **Описание**

_Страница оформлена как последовательность карточек-спринтов. Каждая карточка содержит:_

- заголовок этапа
- стилизованное изображение
- текст с личными ощущениями и выводами
- интерактивную кнопку «Like»

В конце страницы расположена кнопка «Сохранить на память», которая открывает диалоговое окно в стиле старых операционных систем.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties, `clamp()`, анимации)
- JavaScript (лайки и управление `<dialog>`)
- Шрифты: Inter (переменный) и Press Start 2P

## **Функциональность**

- Адаптивная вёрстка
- Анимация сердца при лайке
- Модальное окно с кастомным оформлением
- Плавные переходы и hover-эффекты
- Пиксельная стилистика интерфейса
